# EAS 4610 Final Project
This repo contains a script that describes the vertical temperature profile in a 1-D column of ice in an ice sheet using advection-diffusion numerical methods.

<img width="500" height="361" alt="image" src="https://github.com/user-attachments/assets/110ec6b4-1e44-4724-b76d-f217240a46d0" />

Above is the setup used, from [research by Moreno-Parada, Robinson, Montoya, and Alvarez-Solas.](https://tc.copernicus.org/articles/18/4215/2024/)

Here, θ is the temperature of the ice, which will be solved for at discrete intervals along the length of the ice column.
